# 29. SEO

## Objetivo

Toda página pública debe optimizarse para buscadores.

---

# Renderizado

Priorizar Server Components siempre que sea posible.

Utilizar Client Components únicamente cuando exista interacción.

---

# Metadata

Cada página debe definir:

title

description

openGraph

robots

alternates

---

# URL

Las URLs deben ser:

Descriptivas

Estables

Legibles

Ejemplo

/servicios/cambio-aceite

No

/service?id=52

---

# Imágenes

Siempre utilizar:

next/image

Formato

WebP

AVIF

---

# Performance

SEO depende directamente del rendimiento.

Optimizar:

LCP

CLS

INP

---

# Datos estructurados

Cuando sea posible utilizar:

JSON-LD

Schema.org

---

# Enlaces

Utilizar correctamente:

next/link

Evitar enlaces rotos.

---

# Objetivo

Toda página pública debe poder indexarse correctamente sin modificaciones adicionales.
