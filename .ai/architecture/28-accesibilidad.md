# 28. Accesibilidad

## Objetivo

Toda persona debe poder utilizar la aplicación independientemente de sus capacidades.

La accesibilidad forma parte del diseño.

---

# HTML Semántico

Utilizar siempre etiquetas correctas.

header

main

section

article

nav

footer

button

form

label

---

# Navegación

Toda funcionalidad debe poder utilizarse únicamente mediante teclado.

Nunca depender exclusivamente del ratón.

---

# Focus

Nunca eliminar outline sin proporcionar una alternativa.

Los elementos interactivos deben indicar claramente el foco.

---

# Imágenes

Toda imagen debe incluir:

alt

descriptivo.

Nunca utilizar:

alt="imagen"

---

# Botones

Los botones deben describir la acción.

Correcto

Guardar

Reservar cita

Cerrar sesión

Incorrecto

Click aquí

---

# Formularios

Todos los campos deben disponer de:

label

placeholder únicamente como ayuda visual.

---

# Contraste

Todos los colores deben cumplir WCAG AA como mínimo.

---

# Animaciones

Respetar usuarios con reducción de movimiento.

Utilizar:

prefers-reduced-motion

cuando sea necesario.

---

# Objetivo

La accesibilidad no debe considerarse una funcionalidad opcional.
