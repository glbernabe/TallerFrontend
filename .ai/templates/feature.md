# Feature Template

Antes de escribir código analiza:

- ¿Qué modelos de dominio hacen falta?
- ¿Qué interfaces hacen falta?
- ¿Qué DTO hacen falta?
- ¿Qué mappers hacen falta?
- ¿Qué repositories hacen falta?
- ¿Qué services hacen falta?
- ¿Qué use cases hacen falta?
- ¿Qué hooks hacen falta?
- ¿Qué componentes hacen falta?
- ¿Qué páginas hacen falta?
- ¿Qué constantes hacen falta?
- ¿Qué tests hacen falta?
- ¿Qué documentación debe actualizarse?

No implementes directamente.

Primero presenta el plan.

Después implementa cada archivo respetando la arquitectura existente.

Nunca omitas capas.

Nunca coloques lógica en una capa incorrecta.

Si detectas que la funcionalidad rompe la arquitectura existente, explica el problema antes de generar código.
