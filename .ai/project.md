# Mercedes Frontend

Proyecto oficial para Autotalleres Orihuela.

Tecnologías:

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS v4
- FastAPI
- Google Identity Services
- Clean Architecture

Objetivo:

Crear una aplicación escalable que permita:

- Login
- Reservas
- Carrito
- Vehículos
- Integración con Spiga+
- APIs Mercedes
