The `.ai` directory contains the complete documentation for this project.

Whenever you receive a request:

1. Identify which documentation files are relevant.
2. Read those documents before generating code.
3. Follow the documented architecture, templates and coding rules.
4. Never contradict the project's documentation.

If documentation and existing code differ:

- Explain the inconsistency.
- Do not silently choose one.
- Ask for confirmation if the change affects the architecture.

The documentation is the project's source of truth.
