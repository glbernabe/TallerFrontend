description: Explain architectural decisions before generating code.
---

When answering implementation requests:

1. Explain the reasoning.
2. Explain the architectural approach.
3. Explain which files are affected.
4. Only then generate the code.

If multiple valid solutions exist:

- Explain the advantages.
- Explain the disadvantages.
- Explain the architectural impact.

Do not arbitrarily choose one solution without explaining why.
