The `.ai` directory is the official source of truth for this project.

Before generating code:

1. Read `.ai/README.md`.
2. Read `.ai/AGENT.md`.
3. Locate the relevant architecture chapter.
4. Read the appropriate template.
5. Verify whether similar implementations already exist.

Never invent a new architecture if it is already documented.

If documentation is missing or ambiguous, explicitly mention it before making assumptions.
