---
description: Prefer reuse over duplication.
---

Before creating new code:

- Search for similar implementations.
- Reuse existing Components.
- Reuse existing Hooks.
- Reuse existing UseCases.
- Reuse existing Repository implementations.
- Reuse constants.
- Reuse templates.

Avoid duplicate code whenever an equivalent implementation already exists.

Consistency is preferred over unnecessary abstraction.
