Never generate code immediately.

Before writing any code:

- Fully understand the problem.
- Search the codebase for similar implementations.
- Read the relevant documentation inside `.ai/`.
- Read the appropriate template.
- Validate that the proposed solution follows Clean Architecture.
- Prefer extending the current architecture instead of introducing new patterns.

If any architectural uncertainty exists, explain it and ask for clarification before implementing the solution.
